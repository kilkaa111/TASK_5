# День 5. Сайт

У ООО «Рога и Копыта» уже есть база данных (день 2), API (день 3) и программа для менеджеров (день 4). Теперь компания хочет, чтобы клиенты могли **сами** заказывать товары — через сайт.

Сегодня ты доделаешь такой сайт: каталог товаров, корзина и кнопка «Оформить заказ». Страница уже свёрстана и умеет получать данные из API. Осталось найти несколько ошибок и дописать пару кусочков кода.

> Не пугайся, если что-то в коде непонятно. Чтобы решить задания, не нужно понимать каждую строчку: достаточно внимательно читать и сравнивать с готовыми примерами рядом.

---

### Как это работает — за одну минуту

```
 Сайт (ShopSite)  ──запрос──►  API (ShopAPI)  ──SQL──►  База shop
 страница в браузере ◄─ответ─   из дня 3      ◄───────   из дня 2
```

Сайт состоит из трёх видов файлов:

| Файл | Язык | За что отвечает |
|---|---|---|
| `index.html` | **HTML** | **Что** есть на странице: заголовки, списки, поля, кнопки |
| `css/style.css` | **CSS** | **Как это выглядит**: цвета, размеры, отступы |
| `js/app.js` | **JavaScript** (JS) | **Что страница делает**: загружает товары, реагирует на нажатия |

- Сайт, как и программа из дня 4, ничего не знает про базу. Ему нужны товары — он просит их у API: `GET /products`.
- **API** уже исправлено и работает правильно, его трогать не нужно. Его нужно просто запустить.
- В API добавлена одна настройка — **CORS**. Без неё браузер не разрешил бы странице читать ответы API: это защита от чужих сайтов.

## Шаг 4. Осмотрись

Все задания — в папке `ShopSite`:

| Файл | Что в нём |
|---|---|
| `index.html` | Разметка страницы |

**Как связаны HTML и JS.** В `index.html` у элемента есть `id`:

```html
<input id="search" type="text" placeholder="Поиск по названию">
```

В `app.js` этот элемент находят по `id` и дальше работают с ним:

```js
const searchInput = document.getElementById('search');
searchInput.value                                    // текст, который ввёл пользователь
searchInput.addEventListener('input', applyFilter);  // когда текст меняется — вызвать applyFilter
```

### Инструменты разработчика — твой главный помощник

Нажми **F12** на странице сайта. Откроется панель разработчика. Тебе понадобятся три вкладки:

| Вкладка | Что там |
|---|---|
| **Console** (Консоль) | Ошибки JavaScript — **красным**, с именем файла и номером строки. Сюда же пишет `console.log(...)` |
| **Network** (Сеть) | Все запросы страницы. Нажми на запрос `products` → вкладка **Response** (Ответ) — увидишь, что именно прислало API |
| **Elements** (Элементы) | Как устроена страница сейчас. Можно навести на элемент и посмотреть его классы и стили |

> 💡 Не понимаешь, что лежит в переменной? Напиши в коде `console.log(имяПеременной);`, обнови страницу и посмотри в Console. Это самый простой способ отладки. Только не забудь убрать лишние `console.log` перед сдачей.

### Шпаргалка по JavaScript

Многое похоже на C# из прошлых дней.

```js
const text = searchInput.value;             // const — переменная, которую не будем менять
let total = 0;                              // let — переменная, которую будем менять
if (x === 5) { ... }                        // === равно, !== не равно, && и, || или
total += 10;                                // прибавить 10 к total
products.filter(p => p.price > 100)         // новый список: только товары дороже 100 (как Where в C#)
cart.find(l => l.productId === 5)           // первая строка корзины с товаром 5, или undefined
for (const line of cart) { ... }            // пройти по всем строкам корзины (как foreach в C#)
'Кофе'.toLowerCase()                        // 'кофе' — все буквы маленькие
'Пончики'.includes('онч')                   // true — в строке есть такой кусок (как Contains в C#)
Number('5')                                 // превратить текст '5' в число 5
`Итого: ${total} ₽`                         // строка, в которую подставляется total (как $"..." в C#)
const products = await getProducts();       // await — «дождись ответа от API»
return;                                     // выйти из функции, дальше код не выполняется
```

> ⚠️ В JavaScript большие и маленькие буквы различаются **везде**: `price` и `Price` — это разные имена.

### Задание 4. Поиск — напиши сам

Поле «Поиск по названию» пока ничего не делает. Допиши фильтр 2 в функции `applyFilter`.

- **Цифры не совпадают с «Проверь себя»** — возможно, база изменилась, пока ты тестировал. Загрузи `shop.sql` заново (шаг 1).
